# Telegram bug reports

Website: https://bugs.telegram.org/

Telegram's public tracker supports bug reports and feature suggestions.
Sign-in uses an existing Telegram account. Reports, attachments and
comments are public.

## Bug report format

The “New Issue” form collects:
- Affected app/device, including app and OS versions.
- Optional screenshot or video; skipping requires confirmation.
- Description, in English.
- Steps to reproduce, in a separate field.
- Title, either suggested automatically or entered manually.

Description and reproduction steps are entered before the title.
There are no separate actual-result or expected-result fields in
the observed form.

A final preview shows the title, description, reproduction steps,
device information, tags and attachments before submission.
